# Storyknows AI 写作

## 本地开发

在仓库根目录 `.env.local` 配置 `DEEPSEEK_API_KEY`，其余可选项见 `.env.story-ai.example`。修改后重启开发服务。密钥只由 Vite 的服务端中间件读取，不使用 `VITE_` 前缀，不放入浏览器代码。

未配置密钥时界面仍可使用；AI 请求返回“尚未配置”的提示，不改变正文或布局。自动化测试使用模拟响应，不需要密钥、不产生模型费用。

## 交互与数据

- 沉浸写作右下角羽毛：生成最多 120 字的梗概，预览可编辑、重新生成、取消、采用。采用后同一便签显示梗概，原文保留；可切换原文/梗概。
- 白板工具栏星光：选中已有文字或其容器后操作；没有选择时读取当前白板所有可写片段。生成的大纲不会再次作为原文输入。
- 整理大纲只组织已有情节；生成大纲允许提出标注为 AI 建议的情节。支持起承转合、三幕式及暂未归位/人物/设定。
- 预览暂存在界面中，不写入场景；刷新会丢弃未采用预览。点击空白或切换工具不会丢失预览。采用后生成原生画布对象，作为一次可撤销操作。
- 正文、梗概及来源关系通过元素 `customData.storyknows` 随场景保存；JSON 文件导出可保留数据。PNG/SVG 是视觉导出，不能代替场景备份。
- 来源删除后引用保留，点击来源入口显示“来源已删除”；撤销删除后恢复。复制来源和大纲时引用跟随复制对象；单独复制大纲仍指向原来源。
- 节奏曲线是可编辑的画布装饰线，采用后移动单卡不会自动重绘整条曲线。

## 服务端与部署

前端 POST `/api/story-ai`；`api/story-ai.ts` 是 Node 请求处理器，可接入支持该约定的函数平台，或挂载到 Node 服务。**单独上传静态 build 目录不包含 AI 服务**，需同时部署此接口；未来桌面本地服务可复用请求/响应类型，不需要修改画布数据。

默认 DeepSeek 地址与模型可由环境变量覆盖。接口验证来源 ID、节点类型、长度和组织模式约束；长文本分块整理后再编排，不静默截断。当前上限 50 个片段、合计 20 万字符，超时 120 秒。长文可能因超时失败，前端会保留已有内容供重试。

已有每 IP 每分钟 10 次、每进程每日默认 200 次的基础限制，`STORY_AI_DAILY_LIMIT` 可配置。它们不是跨实例的全局额度；公开发布自费体验版前，应配置网关共享限流及供应商额度限制。接口收到的正文会发给所配置的模型服务。

覆盖梗概采用与全文保留、原生编辑后切换、失败/取消与迟到响应、预览采用与撤销、来源 ID 验证、复制关联、服务端未配置密钥/错误/长度重试。模型实际输出质量及真实 DeepSeek 联调尚待配置密钥后验证。
